# 3D Basketball Game V1

A simple browser-based 3D basketball prototype made with Three.js.

## Run locally
You can open `index.html` in a browser, or use a local web server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `game.js`, and this README.
3. Open **Settings → Pages**.
4. Set the source to your main branch and `/ (root)`.
5. Save. GitHub will give you a playable Pages URL.

## Controls
- WASD / Arrow keys: move
- Shift: sprint
- Hold Space: charge shot
- Release Space: shoot
- R: reset ball

## V1 features
- 3D basketball court
- Player movement
- Sprinting
- 3D ball
- Shooting + shot meter
- 2/3 point scoring
- Basic CPU defenders
- Scoreboard and game clock
- Restart screen
